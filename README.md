# 개인정보처리방침·지원 페이지

- 공개 주소: https://seungbinbaik.github.io/weakest-kid/
- 파일: `index.html`(지원), `privacy.html`(개인정보 처리방침), `style.css`, `.nojekyll`.
- 언어: 한국어, 일본어, 번체 중국어(대만), 번체 중국어(홍콩), 영어. 한 페이지에 다섯 구역이 있고, 위쪽 링크로 이동해요.
- 외부 스크립트, 분석 도구, 추적 도구는 없어요. 순수 HTML과 CSS예요.

## 공개 방법

1. GitHub에 공개 저장소 `weakest-kid`를 만들어요.
2. 이 `site/` 폴더의 파일을 저장소 루트에 올려요.
3. 저장소 Settings → Pages에서 Source를 `main` 브랜치 `/ (root)`로 정해요.
4. 몇 분 뒤 위 주소에서 두 페이지를 확인해요.
5. App Store Connect와 Play Console에 두 주소를 넣어요. 지원 URL은 `index.html` 주소, 개인정보 처리방침 URL은 `privacy.html` 주소예요.

## 수정할 때

- 내용을 바꾸면 두 페이지의 「최종 수정」 날짜도 바꿔요.
- 사실의 근거는 `docs/RELEASE.md` §0·§2-1, `docs/APP_REVIEW_NOTES.md`, `docs/STORE_LISTING.md`예요.
- 숨긴 묶음(101층)은 이 페이지에 쓰지 않아요.
